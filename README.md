# SkyVoyager ✈️ – Airline Reservation System

## 📌 Project Overview

**SkyVoyager** is a web-based Airline Reservation System developed using **XAMPP (Apache, PHP, MySQL)** for the backend and **HTML, CSS, JavaScript** for the frontend.

The system allows **customers to search and book flights**, while **administrators can manage flights, users, and schedules** via a dedicated dashboard.

## 🚀 Key Features

### ✅ User Functionality
- User Registration & Authentication (Customer & Admin)
- Flight Search (One-way & Round Trip)
- Seat Selection
- Booking & Ticket Generation
- Payment Process (Non-functional placeholder)

### 🛠 Admin Features
- Flight Management (Add/Edit/Delete Flights)
- City & Airline Setup
- Booking Overview & Passenger Details
- Mark Flights as *Departed / Arrived / Issue Reported*
- Dashboard with Real-time Flight Status
